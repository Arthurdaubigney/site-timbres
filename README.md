# Expertise Philatélie

Site vitrine (HTML5 + Tailwind CSS) d'estimation et de rachat de timbres rares, avec formulaire Tally intégré (`Me0lOY`).

```bash
npm install
npm run build   # compile src/input.css -> dist/style.css
npm run dev     # mode watch
```

Page : `index.html` · Images : `assets/img/` (photos Pexels).
